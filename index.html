Story Game Builder

Create a branching visual-novel style story game with NPC dialogue, choices, and multiple endings.

1) Story Script (JSON)

Define your game using nodes and choices. Each node should include: id, speaker, text, and optional choices.

2) Characters

Add character profile cards and avatar hints. You can paste an avatar URL or write your own drawing prompt.
